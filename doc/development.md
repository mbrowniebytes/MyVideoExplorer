### clone repo

> git clone [repo]

### initialize a python env

using [venv](https://pythonguides.com/virtual-environments-python/)
> py -3.14 -m venv .venv

### activate env

> source .venv/Scripts/activate

### install packages

using [pip](https://pip.pypa.io/en/stable/getting-started/)
> pip install -e .  
> pip install --group dev

if do src/ refactors
delete `build/` or  
> pip install -e . --force-reinstall

### run app

Use the package entry point instead of running the file directly:
> python -m MyVideoExplorer

or after install:
> myvideoexplorer

### list outdated packages
list top level packages and all dependencies
> pip list --outdated
> pip install -U [pkg]

### upgrade pip

> py -m pip install --upgrade pip

### update lock file pylock.toml

> py -m pip lock -e .

### install from lock file pylock.toml

#### Folder Structure

```
MyVideoExplorer/
├── asset/                     # Assets (fonts, icons, etc.)
├── cfg/                       # Application configuration files
├── db/                        # Local database storage (DuckDB)
├── doc/                       # Documentation and AI context
├── log/                       # Application log files
├── src/MyVideoExplorer/
│   ├── app/                   # App lifecycle, AppContainer (DI), AppController, AppSignals, MainWindow
│   ├── app_loading/           # Splash and loading screen
│   ├── db/                    # DuckDB models, repositories, file scanner & query filters
│   ├── file_list/             # Media file table/list view
│   ├── folder_filter/         # Folder search and filtering logic
│   ├── folder_list/           # Folder directory tree/list view
│   ├── folder_nav/            # Navigation breadcrumbs and path bar
│   ├── image_list/            # Media thumbnail and poster grid view
│   ├── lang/                  # Localization and translations
│   ├── media_info/            # Media metadata display and detail panels
│   ├── media_info_section/    # Metadata sections and layout
│   ├── media_info_side/       # Side info preview panel
│   ├── media_info_tabs/       # Right panel tabbed workspace manager
│   ├── settings/              # Settings models, persistence, and dialogs
│   ├── tag_cloud/             # Tag generation, browsing, and filter widget
│   ├── theme/                 # QSS stylesheets, palettes, and styling
│   ├── utils/                 # Path, file, datetime, and OS utilities
│   ├── video_player/          # Video playback integration
│   └── widgets/               # Reusable custom Qt components
└── test/                      # Test suite (mirrors src/ structure)
```

#### UI Component Mapping

The application uses a `QSplitter` to divide the screen:

- **Left Panel** (`folder_nav/`, `folder_list/`, `folder_filter/`): Directory navigation, selection, and filtering.
- **Right Panel** (`media_info_tabs/`): Tabbed workspace containing:
    - **media**: Content browsing via `file_list/` (table) or `image_list/` (thumbnails)
    - **info**: Metadata inspection (`media_info*`), tags (`tag_cloud/`)
    - **⚙**: Application preferences (`settings/`)
